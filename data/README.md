# Data Directory

This directory is used to store various data files used by the Deep Deep Research v2 system.

## Contents

- Source data fetched from various APIs
- Cached research results
- Intermediate processing data
- Configuration files

## Important Notes

- Large data files should not be committed to the repository
- Sensitive data should be excluded (see .gitignore)
- Use appropriate data formats (JSON, CSV, etc.) based on the use case
