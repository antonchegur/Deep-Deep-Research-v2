# PDF Report Generation System Guide

## Overview

The PDF Report Generation System is a powerful component of Deep Deep Research v2 that enables the creation of beautiful, well-structured PDF reports from research results. The system provides a flexible API for generating PDFs with various styles, formats, and content types.

## Key Features

- **Multiple PDF Backends**: Support for both ReportLab and FPDF2 PDF generation libraries
- **Template-Based Generation**: Pre-defined templates for different report styles (modern, academic, business)
- **Rich Content Support**: Text, tables, charts, images, lists, and more
- **Dynamic Styling**: Customizable stylesheets for consistent formatting
- **Automatic Elements**: Table of contents, page numbering, headers, and footers
- **Bibliography Integration**: Works with the Reference Management System for proper citations and bibliography
- **Visualization**: Chart rendering with matplotlib integration
- **High-Level API**: Simple interface for generating complete reports from research results

## Basic Usage

### Creating a Simple Report

```python
from src.pdf_generation import create_simple_report, ReportLibrary

# Create a simple report with a title and content
pdf_path = create_simple_report(
    title="Research Findings",
    content="This is a simple report with basic content.",
    output_path="simple_report.pdf",
    author="Deep Deep Research v2",
    include_date=True,
    library=ReportLibrary.REPORTLAB
)

print(f"Report generated at: {pdf_path}")
```

### Using the Report Service

```python
from src.pdf_generation import ReportService, ReportLibrary

# Create a report service with a specific template style
report_service = ReportService(
    template_name="modern",  # Options: "modern", "academic", "business"
    library=ReportLibrary.REPORTLAB
)

# Research results from your system
research_results = {
    "query": "Impact of renewable energy on climate change",
    "summary": "Renewable energy technologies play a crucial role...",
    "findings": [
        {
            "title": "Current Renewable Energy Adoption",
            "content": "Global renewable energy capacity has grown significantly..."
        },
        # More findings...
    ],
    "sources": [
        {
            "title": "IRENA Renewable Capacity Statistics 2023",
            "source_name": "International Renewable Energy Agency",
            "url": "https://www.irena.org/publications/...",
            "source_type": "report"
        },
        # More sources...
    ],
    "conclusion": "Accelerating the transition to renewable energy is essential..."
}

# Generate a PDF report
pdf_path = report_service.generate_report_from_research_results(
    research_results=research_results,
    output_path="research_report.pdf",
    title="Renewable Energy Impact Report"
)

print(f"Report generated at: {pdf_path}")
```

### Creating a Custom Report

```python
from src.pdf_generation import (
    PDFReport, ReportConfig, ReportLibrary, 
    TextElement, TableElement, ChartElement, ImageElement,
    HeaderElement, FooterElement, ListElement, PageBreakElement
)
import matplotlib.pyplot as plt
import numpy as np

# Create a report configuration
config = ReportConfig(
    title="Custom Research Report",
    author="Deep Deep Research v2",
    include_toc=True,
    include_page_numbers=True,
    library=ReportLibrary.REPORTLAB
)

# Create a report
report = PDFReport(config)

# Add header and footer
report.add_element(HeaderElement(
    text=config.title,
    height=40,
    include_date=True,
    include_page_number=True
))

report.add_element(FooterElement(
    text=f"Generated by {config.author}",
    height=30,
    include_page_number=True
))

# Add title
report.add_element(TextElement(
    text="Impact of AI on Healthcare",
    x=72, y=100,
    style_name="title"
))

# Add executive summary
report.add_element(TextElement(
    text="Executive Summary",
    x=72, y=180,
    style_name="heading1"
))

report.add_element(TextElement(
    text="This report examines the transformative impact of artificial intelligence...",
    x=72, y=210,
    width=450,
    style_name="body"
))

# Add page break
report.add_element(PageBreakElement())

# Add a chart
x = np.arange(5)
y1 = [10, 15, 22, 32, 45]
y2 = [8, 12, 17, 25, 40]

plt.figure(figsize=(8, 4))
plt.plot(x, y1, 'b-', label='Diagnostic Accuracy')
plt.plot(x, y2, 'r--', label='Treatment Optimization')
plt.xlabel('Years from Present')
plt.ylabel('Impact Score')
plt.title('Projected AI Impact on Healthcare')
plt.xticks(x, ['1', '2', '5', '10', '15'])
plt.legend()
plt.grid(True)

# Save chart to temporary file
import tempfile
with tempfile.NamedTemporaryFile(suffix='.png', delete=False) as tmp:
    chart_path = tmp.name
plt.savefig(chart_path)
plt.close()

# Add chart to report
report.add_element(TextElement(
    text="AI Impact Projection",
    x=72, y=72,
    style_name="heading2"
))

report.add_element(ImageElement(
    image_path=chart_path,
    x=72, y=100,
    width=450
))

# Add table
report.add_element(TextElement(
    text="AI Applications in Healthcare",
    x=72, y=380,
    style_name="heading2"
))

table_data = [
    ["Application", "Current Adoption", "5-Year Projection"],
    ["Medical Imaging Analysis", "Medium", "High"],
    ["Clinical Decision Support", "Low", "Medium"],
    ["Virtual Nursing Assistants", "Low", "Medium"],
    ["Drug Discovery", "Medium", "High"],
    ["Personalized Medicine", "Low", "High"]
]

report.add_element(TableElement(
    data=table_data,
    x=72, y=410,
    col_widths=[200, 125, 125]
))

# Generate PDF
pdf_path = report.generate("custom_report.pdf")
print(f"Report generated at: {pdf_path}")

# Clean up
import os
os.unlink(chart_path)
```

## Customizing Styles

### Using StyleSheet

```python
from src.pdf_generation import StyleSheet, ColorScheme, TextStyle, TextAlignment

# Create a custom color scheme
color_scheme = ColorScheme(
    primary="#0066cc",      # Blue
    secondary="#ff9900",    # Orange
    accent="#009933",       # Green
    text="#333333",         # Dark gray
    background="#ffffff",   # White
    heading="#0066cc"       # Blue
)

# Create a custom stylesheet
stylesheet = StyleSheet()
stylesheet.apply_color_scheme(color_scheme)

# Customize specific styles
stylesheet.heading1 = TextStyle(
    font_family="Helvetica-Bold",
    font_size=24,
    color=color_scheme.heading,
    alignment=TextAlignment.LEFT,
    line_spacing=1.2,
    bold=True
)

# Use in ReportConfig
config = ReportConfig(
    title="Styled Report",
    author="Deep Deep Research v2",
    stylesheet=stylesheet
)

report = PDFReport(config)
# Add elements...
```

## Integration with Research System

The PDF Report Generation System integrates seamlessly with the Research System:

1. Research queries are processed by the Source Management System
2. Sources are analyzed and synthesized by the GPT-4 Turbo Integration
3. References are managed by the Reference Management System
4. The Content Organization System structures the information
5. The PDF Report Generation System creates the final report

This workflow ensures that all research results are presented in a professional, consistent format with proper citations and high-quality visualization.

## Best Practices

1. **Use Templates**: For consistent formatting, use the built-in templates rather than creating reports from scratch.

2. **Style Consistently**: Define styles once and apply them consistently throughout the report.

3. **Optimize Images**: Compress images and charts before adding them to reports to keep file sizes manageable.

4. **Use Vector Charts**: When possible, use vector-based charts (PDF charts in ReportLab) for better scalability.

5. **Test Pagination**: Always test how your report looks across multiple pages to ensure proper pagination.

6. **Handle Large Reports**: For very large reports, consider breaking them into sections or using memory optimization techniques.

7. **Include Metadata**: Always include proper metadata (title, author, keywords) for better searchability.

## Advanced Features

- **Customizing Headers/Footers**: Headers and footers can be customized with dynamic content like page numbers, dates, and logos.
- **Table of Contents Generation**: Automatic TOC generation based on heading structure.
- **PDF Bookmarks**: Bookmarks can be added for easy navigation within the PDF.
- **Hyperlinks**: Internal and external links can be added to enhance navigation.
- **Page Templates**: Custom page templates for specialized pages (cover, appendices, etc.).
- **Watermarks**: Background watermarks or images can be added to pages.

## Troubleshooting

- **Images Not Showing**: Ensure image paths are absolute or correctly relative to the execution directory.
- **Font Issues**: When using custom fonts, make sure they are properly registered with the PDF library.
- **Memory Errors**: For large reports, consider using streaming/partial generation options.
- **Chart Quality**: Adjust DPI settings for better chart quality in the final PDF.
- **Bibliography Issues**: Check that the Reference Management System is properly initialized and sources have the correct format.
